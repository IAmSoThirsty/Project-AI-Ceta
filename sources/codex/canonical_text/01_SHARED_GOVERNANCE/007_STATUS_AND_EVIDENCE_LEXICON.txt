STATUS AND EVIDENCE LEXICON

CREATED — The artifact exists. No test or correctness claim is implied.
MODIFIED — An existing artifact changed. No verification claim is implied.
DRAFTED — Substantive content exists, but authoring remains open or material content gaps may remain.
CONTENT-COMPLETE — All required substantive section content exists for the declared scope and the authoring pass is complete. This state does not imply source reconciliation, hostile review, owner acceptance, implementation, testing, verification, readiness, ratification, or publication.
SOURCE-RECONCILED — The content has been checked against all applicable supplied sources, dependencies, and related Codex sections, with conflicts and unresolved gaps recorded.
HOSTILE-REVIEWED — The content has undergone structured challenge for omission, contradiction, false claims, unusable requirements, missing recovery, and human-AI control failures.
OWNER-ACCEPTED — The accountable human owner has accepted the exact content and artifact identity. No agent may infer this state.
TESTED — A named test or test set was executed; the exact result must be stated.
VERIFIED — The defined evidence and acceptance method support the bounded claim.
NOT VERIFIED — Verification did not occur or did not cover the claim.
FAILED — An attempted action or acceptance method produced a defined failure.
BLOCKED — A prerequisite prevents the affected work from safely or truthfully advancing.
PENDING — Work or a decision remains scheduled or awaited.
UNKNOWN — The state cannot currently be established from adequate evidence.
PARTIAL — Only an explicitly identified subset is complete or evidenced.
SIMULATED — The result was produced in a simulation or mock context, not the claimed live context.
STALE — Evidence or state exceeded its permitted freshness boundary.
QUARANTINED — The artifact or action is isolated from trusted use pending resolution.
READY — Every criterion in the declared readiness scope is closed with required evidence.
NOT READY — One or more mandatory readiness criteria remain unresolved.
READY EXCEPT — Readiness is established except for explicitly bounded listed conditions where this label is permitted.
BLOCKED BY — Readiness cannot advance because named prerequisites remain unresolved.

No averaged score, visual color, agent confidence, elapsed effort, file count, or polished presentation may silently convert one state into another.
