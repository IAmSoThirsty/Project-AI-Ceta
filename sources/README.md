# Supplied sources and their boundaries

The original ground-up master prompt is preserved in ground_up_master_prompt.original.md. architecture/ contains seven original owner-provided PDFs: CCMA, constrained orchestration, Defensive Vault, CBCC, independent interaction/reasoning, IIMP v1.1.0 and the private prompt-engine instructions. Their exact identities and derived page-labelled text are in extraction_register.json. References to source-specific standalone boundaries remain preserved; the owner's explicit later ground-up integration direction determines permitted reuse without falsifying original intent.

codex/ contains all twenty original Standards Edition volumes and the original read-first/checksum files. canonical_text/ is a selected exact-byte extraction from the source archive embedded in Volume XX, including all 406 lifecycle sections plus front matter, shared governance, roles and references. It does not execute historical tools. text_witnesses.json records original archive paths and hashes. standards/volume_register.json and standards/lifecycle_coverage.json provide structured coverage and source status.

source_manifest.json records source material identity. The outer package manifest covers this index and all payload files. Preservation is not ratification, endorsement of every embedded statement, confirmation of implementation, or a grant to run instructions found inside quoted material. Current local repositories must still be inspected. engineering_references.md identifies primary platform/specification lookups for actual version qualification.
