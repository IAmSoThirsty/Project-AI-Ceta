# Threat and assumption engineering

threat_register.json lists design failure conditions with component and acceptance bindings. assumption_register.json identifies what must be established, revalidation triggers and dependent tests. They are not reports of attacks against the user or claims of achieved protection. Implement boundary enforcement and attempt the named bypasses with controlled fixtures. Keep local process separation, OS isolation, independent administration and hardware attestation distinct.

Implementation proceeds under the root AGENTS.md and build/work_packages.json. Preserve runtime evidence statuses and the original handoff manifest.
