# Source custody and attribution

The bundled Codex volumes, selected original textual witnesses, original architecture PDFs and prior ground-up prompt are owner-supplied reference material. Their original notices, status and authorship remain unchanged. Inclusion in this private implementation package does not create a new blanket public license or ratify historical drafts. Before publishing a derivative product, reconcile licenses and attribution for every actual reused source and dependency.

The authoring package introduces new requirement IDs, component contracts, policies, work orders, schemas and package-validation tooling to organize this specific rebuild. These new IDs are not original Codex clause identifiers. Source-derived text is retained in explicit source or specification locations and references its provenance. External engineering sources are linked and summarized narrowly rather than mirrored wholesale.

No personal chat archive, screenshots of family/legal correspondence, production credentials, model weights, executable third-party source tools or standalone font files are bundled. The original supplied PDFs remain byte-preserved; their normal embedded document resources remain part of those original documents. Page-labelled text files are derived retrieval aids, not replacements for signed or original bytes.

The historical CETA Next Major Update planning ZIP was visible in Library metadata but could not be materialized through the available raw-byte route. It is not represented as included. The subsequently supplied ground-up master prompt is included in full and is the direct organizing source for this package. Local repository code and current worktree state remain implementation-time sources to inspect in the owner's authorized environment.
