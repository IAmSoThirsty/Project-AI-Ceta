# Operating procedures

These runbooks specify supported preconditions, operator actions, observed outcomes, fault behaviour and evidence for the implemented product. Codex must connect each procedure to real native controls or verified CLI commands. No future command is labelled already runnable. Use temporary profiles for qualification; production recovery, cutover and publication require the action-specific authority.

Implementation proceeds under the root AGENTS.md and build/work_packages.json. Preserve runtime evidence statuses and the original handoff manifest.
