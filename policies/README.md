# Prewritten policy set

The 24 policy documents define intended conduct, authority, enforcement and proof obligations. policy_registry.json links their full texts and requirement groups. These are specifications to compile and implement, not an already active security policy engine. Configuration defaults deny activation until the appropriate current grants and qualifications exist. Amendments must be versioned, reviewed and authorized; policy prose alone cannot enforce an OS boundary.

Implementation proceeds under the root AGENTS.md and build/work_packages.json. Preserve runtime evidence statuses and the original handoff manifest.
