# Inactive design defaults

design_defaults.json establishes an inactive, no-grants initial design. Numeric budgets are proposed engineering defaults to measure and ratify where required. Null identity/model/toolchain/approval values mean UNRESOLVED or NOT_GRANTED, not hidden fallbacks. Never ship placeholders as qualified resources or silently create network, capture, signing or paid-compute permissions.

Implementation proceeds under the root AGENTS.md and build/work_packages.json. Preserve runtime evidence statuses and the original handoff manifest.
