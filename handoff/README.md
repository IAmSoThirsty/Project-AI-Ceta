# Continuing the implementation

continuity.json is the truthful initial handoff state. Once Codex begins real work, preserve this source cut and create the current working continuity record inside the authorized worktree. Record the actual branch/commit, dirty paths, live workers, last test commands, failures, unresolved effects, decisions, authority and next exact operation. Do not imply the new package has already been installed or has exercised the user's hardware.

An interruption should leave enough real evidence for a later agent to continue without guessing. References to inaccessible files remain unavailable rather than being reconstructed from memory. A report of unavailable hardware or independent review keeps the affected gate open while ordinary source work continues. The final review must reconcile the whole scope, not only the last successful increment.
