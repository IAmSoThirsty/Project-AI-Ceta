## Technical continuity

Companion identity is a stable logical record with role, human relationship scope, accepted instructions and model execution lineage. It survives an explicitly recorded model replacement because context and history live in governed storage. Runtime session and configuration identity change when the executing model changes. The interface accurately distinguishes remembered summaries, exact retrieved messages, current observations and inferred reconstruction.

Every new session compiles a continuity envelope from accepted state. It includes active objectives, unresolved questions, obligations, latest resource evidence, applicable preferences, rejected interpretations, pending effects and observation gaps. Stale claims carry their invalidation reason. The model cannot fill a missing historical record with a plausible quotation.

## Memory planes

Working memory holds ephemeral active cognition; short-term memory keeps the current task coherent; long-term memory retains policy-permitted evidence, procedures and explicitly accepted preferences. These classes share one record/lineage model. Retrieval and graph materialization are replaceable projections with current access checks. A source's private status follows its embeddings and summaries.

Clotho creates candidate records without proving them. Lachesis weights relevance without promoting truth. Atropos manages approved retention, supersession and removal without erasing the fact that a recorded decision occurred where retention policy requires minimal audit. The meaning of an old statement remains attributable even when the user's current view changes.

## Correction and contradiction

Store corrections as new evidence. Update active projections and invalidate summaries that relied on the wrong interpretation. Keep genuinely conflicting positions separate until a scoped resolution is justified. A repeated claim, frequent retrieval or many agreeing model roles cannot settle a factual dispute by popularity. Keep the original words and the system's interpretation separate at every stage.
