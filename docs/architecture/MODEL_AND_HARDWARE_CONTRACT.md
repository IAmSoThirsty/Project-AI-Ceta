## Runtime ownership

CETA owns model import, selected asset identity, process lifetime, tokenizer/template, context budget, residency lease, cancellation, qualification and replacement. A pinned llama.cpp-compatible component may provide inference behind that contract. The normal path operates offline after explicit asset provisioning and has no required cloud account or independently installed model service.

A compatibility provider is an explicit separate choice with its own disclosed guarantees and cannot bypass the common request compiler or effect boundary. Local failure never silently sends private context elsewhere. A port number, tag or process name does not prove backend identity.

## Admission

Measure actual executing-machine RAM, commit pressure and supported devices. Budget weights, KV cache, context, output, runtime workspace, host staging, UI and recovery. A GPU displayed by the OS qualifies only after the selected binary reports a compatible device and actual loading supports the claimed placement. Estimates are labeled estimates and configurations are selected by measured quality and responsiveness, not just weight size.

## Prepared requests

Render the pinned template exactly and count its actual tokenization, including roles, tools, attachments and special tokens. Bind the payload, source revisions, model/config, template, tokenizer, authority generation, resource reservation and deadline. Preserve mandatory context on overflow by refusing or requesting a real scope reduction. A stale preview is re-prepared; no silent truncation or objective rewrite is acceptable.

## Qualification

Measure liveness, instructions, exact formatting, source grounding, appropriate uncertainty, planning and supported tools separately. Test ordinary chat through the actual product prompt. Use repeated trials and preserve failure denominators. A fast wrong answer cannot qualify responsiveness. Changes invalidate the affected profile while preserved raw evidence remains readable as history.

## Replacement and failure

Pause dispatch, finish or cancel current owned work, confirm termination where required, invalidate old preparation, verify replacement assets and qualify before use. Lost streams remain uncertain until backend reconciliation. Drafts and task history survive. Unknown resource or containment conditions disable the dependent lane without deleting existing model assets or work.
