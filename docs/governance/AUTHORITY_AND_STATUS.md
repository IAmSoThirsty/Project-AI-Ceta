## Precedence

Respect the executing environment's instruction hierarchy. Within this assignment, current explicit owner scope and legitimate ratified project decisions control; original source documents preserve their stated adoption and revision. The ground-up master prompt is the implementation assignment baseline. This organized package elaborates that baseline; it does not silently supersede a stricter invariant or invent owner approvals. When a material conflict remains, record it and stop only affected activation.

## Document classifications

`OWNER_DIRECTION_RECORDED` records a direct request already present in the source conversation. `DERIVED_REQUIREMENT` organizes that direction and the source prompt. `ENGINEERING_BASELINE_PROPOSED` specifies a ready-to-review implementation choice. `SOURCE_ORIGINAL` means byte-preserved input, not current policy by default. `HISTORICAL_EVIDENCE` describes its original tested configuration only.

## Build status

Use separate fields for specification, implementation, test execution, independent review, installed qualification and activation. The delivered package initializes runtime work as `NOT_STARTED` and acceptance results as `NOT_RUN`. Passing the included package checks changes only document/integrity validation status. It cannot issue a permit, mark a security control implemented or declare the product safe to use.

## Promotion

A requirement becomes implemented when real call sites and tests exist. It becomes verified only under its evidence scope. An installed profile requires actual installed bytes, model, hardware, policy and operating conditions. A seven-day test requires seven real elapsed days. A narrow activated profile cannot erase full-scope remaining work.

## Exceptions

No exception may be invented solely to make a gate green. Proposed changes include source, rationale, affected claims, migration and revalidation. Trust-boundary weakening or reserved-owner choices require the appropriate decision. A missing external dependency receives a blocker, not a fabricated value.
