# Application use cases

Implement orchestration of UI requests through typed core ports. This layer coordinates lifecycle and response presentation; it owns neither independent grants nor a parallel authoritative database. It requests kernel decisions, schedules admitted work, resolves actual results and renders consistent read models. It cannot treat a returned string as a command or write a success flag directly. The lead integrator owns these call sites and all their requirement-to-owner handoffs.

Implementation proceeds under the root AGENTS.md and build/work_packages.json. Preserve runtime evidence statuses and the original handoff manifest.
