# S04 purpose

Use this construction skill to produce: **A focused local implementation change with tests, documentation, and source-bound evidence.**

The required input is: One approved file-level specification, mapped local path, dependencies, write lease, and acceptance IDs.

The skill's distinguishing procedure is: Read the unit and component contracts; inspect the existing target; choose reuse or extension first; implement complete behavior and failure paths; run unit and integration checks; hand off exact artifacts for independent review.

Success is measured by this oracle: **The resulting file satisfies its positive, negative, recovery, and contract obligations without unrelated edits.** The specifically adverse condition is: **A stub or superficial wrapper is presented as end-to-end implementation.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
