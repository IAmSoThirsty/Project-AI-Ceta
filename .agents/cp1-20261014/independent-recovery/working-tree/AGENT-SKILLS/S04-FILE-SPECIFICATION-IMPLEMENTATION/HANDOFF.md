# S04 handoff

## Transfer result

A focused local implementation change with tests, documentation, and source-bound evidence.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: The resulting file satisfies its positive, negative, recovery, and contract obligations without unrelated edits.

The receiver also inspects evidence for the adverse fixture: A stub or superficial wrapper is presented as end-to-end implementation. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
