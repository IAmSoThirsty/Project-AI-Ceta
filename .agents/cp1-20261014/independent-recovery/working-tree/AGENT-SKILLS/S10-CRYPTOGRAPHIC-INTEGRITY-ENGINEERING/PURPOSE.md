# S10 purpose

Use this construction skill to produce: **Domain-bound digests and signatures with protected keys, rotation, and precise verification outcomes.**

The required input is: Approved trust model, established local cryptographic facilities, canonicalization rules, and key lifecycle policy.

The skill's distinguishing procedure is: Pin algorithms and encoding profiles through local reconciliation; hash exact bytes; bind signature domain and version; use protected handles; verify trust separately from mathematics; test rotation, tampering, replay, and truncation assumptions.

Success is measured by this oracle: **A modified payload or wrong-domain signature fails while valid historical evidence remains inspectable.** The specifically adverse condition is: **A home-grown primitive or unsigned local file is described as absolute tamper-proof authority.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
