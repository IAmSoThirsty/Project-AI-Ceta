# S10 handoff

## Transfer result

Domain-bound digests and signatures with protected keys, rotation, and precise verification outcomes.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: A modified payload or wrong-domain signature fails while valid historical evidence remains inspectable.

The receiver also inspects evidence for the adverse fixture: A home-grown primitive or unsigned local file is described as absolute tamper-proof authority. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
