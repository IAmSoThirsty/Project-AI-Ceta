# S06 purpose

Use this construction skill to produce: **Version-bound policy evaluation with exact source traceability and controlled activation.**

The required input is: Owner-approved local rule sources, reconciled language grammar, policy contracts, and invariant tests.

The skill's distinguishing procedure is: Preserve rule text; parse and type-check; implement declared precedence; return explicit unresolved conflicts; bind decisions to proposal and policy digests; test amendments and revocation-sensitive caches.

Success is measured by this oracle: **Missing facts and unresolved conflicts never yield implicit permission.** The specifically adverse condition is: **The implementer invents a constitutional exception to make a test pass.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
