# S06 handoff

## Transfer result

Version-bound policy evaluation with exact source traceability and controlled activation.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Missing facts and unresolved conflicts never yield implicit permission.

The receiver also inspects evidence for the adverse fixture: The implementer invents a constitutional exception to make a test pass. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
