# S06 - Constitutional Policy Implementation

## Input and output

Require: Owner-approved local rule sources, reconciled language grammar, policy contracts, and invariant tests.

Produce: Version-bound policy evaluation with exact source traceability and controlled activation.

## Procedure

Read [prerequisites](PREREQUISITES.md) and [the input contract](INPUTS.md) before acting. Follow [the complete procedure](PROCEDURE.md) for the assigned local task.

1. Preserve rule text.
2. Parse and type-check.
3. Implement declared precedence.
4. Return explicit unresolved conflicts.
5. Bind decisions to proposal and policy digests.
6. Test amendments and revocation-sensitive caches.

## Verification

Missing facts and unresolved conflicts never yield implicit permission.

Use [the verification rules](VERIFICATION.md) and preserve actual source, environment, execution, and artifact evidence. Treat this specific failure as a required adverse fixture: The implementer invents a constitutional exception to make a test pass.

## Failure and handoff

Follow [failure handling](FAILURE-HANDLING.md) when prerequisites, authority, or evidence are insufficient. Transfer results using [the handoff requirements](HANDOFF.md) and [the output contract](OUTPUTS.md). Never substitute a completion narrative for observable evidence.

These are native construction instructions. They do not grant host permissions, activate runtime skills, or authorize effects by themselves. The assigned task and existing CETA authority remain controlling.
