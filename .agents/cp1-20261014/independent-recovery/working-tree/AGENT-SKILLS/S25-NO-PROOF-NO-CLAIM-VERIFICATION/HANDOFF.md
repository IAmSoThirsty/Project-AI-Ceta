# S25 handoff

## Transfer result

A claim ledger classifying each statement as supported, contradicted, incomplete, or not-executed.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Every delivered factual completion claim has an inspectable supporting observation.

The receiver also inspects evidence for the adverse fixture: A plausible summary, generated file count, or confidence score substitutes for actual verification. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
