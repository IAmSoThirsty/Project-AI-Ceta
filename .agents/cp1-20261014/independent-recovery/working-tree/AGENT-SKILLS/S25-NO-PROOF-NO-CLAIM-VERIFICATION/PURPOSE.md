# S25 purpose

Use this construction skill to produce: **A claim ledger classifying each statement as supported, contradicted, incomplete, or not-executed.**

The required input is: A proposed completion statement, artifact references, execution records, tests, and known evidence gaps.

The skill's distinguishing procedure is: Split compound claims; identify required observations; inspect exact evidence; check freshness and scope; separate design, implementation, execution, and qualification; rewrite unsupported statements accurately.

Success is measured by this oracle: **Every delivered factual completion claim has an inspectable supporting observation.** The specifically adverse condition is: **A plausible summary, generated file count, or confidence score substitutes for actual verification.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
