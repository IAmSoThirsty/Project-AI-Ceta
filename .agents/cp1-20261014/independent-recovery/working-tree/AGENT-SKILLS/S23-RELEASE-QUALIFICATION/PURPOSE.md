# S23 purpose

Use this construction skill to produce: **An installed-runtime qualification record and accurate release decision for the exact candidate.**

The required input is: Exact candidate artifacts, source and dependency manifests, mandatory gates, target environments, and update or rollback rules.

The skill's distinguishing procedure is: Validate manifests; install on clean targets; run complete local workflows; test interruption, update, and rollback; verify data preservation and source-to-binary binding; block unmet critical gates.

Success is measured by this oracle: **The distributed bytes are the same bytes exercised by current installed-product tests.** The specifically adverse condition is: **A development-tree test run qualifies a different packaged build.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
