# S23 handoff

## Transfer result

An installed-runtime qualification record and accurate release decision for the exact candidate.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: The distributed bytes are the same bytes exercised by current installed-product tests.

The receiver also inspects evidence for the adverse fixture: A development-tree test run qualifies a different packaged build. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
