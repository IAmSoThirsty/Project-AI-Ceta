# S24 handoff

## Transfer result

A separately produced verification report with reproduced results and explicit discrepancies.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: A distinct verifier reproduces the required outcome from the supplied artifacts and evidence.

The receiver also inspects evidence for the adverse fixture: The verifier approves by trusting the producer narrative or their own earlier implementation. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
