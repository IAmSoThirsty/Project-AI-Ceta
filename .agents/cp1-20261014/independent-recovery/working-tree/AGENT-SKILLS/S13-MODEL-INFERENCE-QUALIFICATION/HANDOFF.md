# S13 handoff

## Transfer result

A measured capability and resource envelope with inference, streaming, cancellation, and cleanup evidence.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: The selected model completes the declared task classes within measured limits and stops safely.

The receiver also inspects evidence for the adverse fixture: Advertised capability or artifact size is treated as measured runtime qualification. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
