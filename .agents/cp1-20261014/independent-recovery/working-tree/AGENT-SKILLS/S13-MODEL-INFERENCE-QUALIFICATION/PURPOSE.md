# S13 purpose

Use this construction skill to produce: **A measured capability and resource envelope with inference, streaming, cancellation, and cleanup evidence.**

The required input is: Exact model artifact, runtime configuration, target hardware, task fixtures, and locality policy.

The skill's distinguishing procedure is: Validate artifacts; measure peak allocations; test supported modalities and context limits; run representative and adverse inputs; verify cancellation and process ownership; qualify fallback only within approved data boundaries.

Success is measured by this oracle: **The selected model completes the declared task classes within measured limits and stops safely.** The specifically adverse condition is: **Advertised capability or artifact size is treated as measured runtime qualification.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
