# Native construction skill library

These 25 reusable procedures guide future development and verification of CETA. Each has a SKILL.md entry point and eight supporting instruction documents plus a folder README. They are documentation-only construction skills, distinct from runtime learned skills in subsystem 06. Load only the relevant skill and direct references for the assigned task.

| Skill | Input | Output |
| --- | --- | --- |
| [S01 Local Baseline Inspection](S01-LOCAL-BASELINE-INSPECTION/SKILL.md) | An owner-selected local CETA root, permitted read scope, and the logical-unit registry. | A source-hashed inventory, entry-point map, current test catalog, and observed integration decisions. |
| [S02 Requirements Decomposition](S02-REQUIREMENTS-DECOMPOSITION/SKILL.md) | Approved product goals, exact user requirements, constraints, and existing acceptance obligations. | A requirement-to-unit map with measurable outputs, dependency edges, and acceptance oracles. |
| [S03 Contract First Design](S03-CONTRACT-FIRST-DESIGN/SKILL.md) | Canonical contract references, producer and consumer owners, local language conventions, and compatibility constraints. | A versioned interface decision with fields, invariants, errors, state semantics, and shared test fixtures. |
| [S04 File Specification Implementation](S04-FILE-SPECIFICATION-IMPLEMENTATION/SKILL.md) | One approved file-level specification, mapped local path, dependencies, write lease, and acceptance IDs. | A focused local implementation change with tests, documentation, and source-bound evidence. |
| [S05 Architectural Dependency Analysis](S05-ARCHITECTURAL-DEPENDENCY-ANALYSIS/SKILL.md) | Subsystem graph, local module graph, shared contracts, and a proposed change set. | Typed build, runtime, data, and optional dependency maps with affected-owner and test impact. |
| [S06 Constitutional Policy Implementation](S06-CONSTITUTIONAL-POLICY-IMPLEMENTATION/SKILL.md) | Owner-approved local rule sources, reconciled language grammar, policy contracts, and invariant tests. | Version-bound policy evaluation with exact source traceability and controlled activation. |
| [S07 Authority Boundary Implementation](S07-AUTHORITY-BOUNDARY-IMPLEMENTATION/SKILL.md) | Principal and capability contracts, trust policy, target resource model, and scoped effect requirements. | Use-time authorization checks with bounded delegation, replay protection, and revocation evidence. |
| [S08 State Transition Engineering](S08-STATE-TRANSITION-ENGINEERING/SKILL.md) | Canonical state owner, transition contract, expected versions, and lifecycle requirements. | A validated state machine with atomic transitions, causal records, and terminal-state rules. |
| [S09 Durable Storage Engineering](S09-DURABLE-STORAGE-ENGINEERING/SKILL.md) | Reconciled storage engine, data schemas, transaction boundaries, retention rules, and fault fixtures. | Durable local records, atomic publication intent, integrity checks, and tested restoration. |
| [S10 Cryptographic Integrity Engineering](S10-CRYPTOGRAPHIC-INTEGRITY-ENGINEERING/SKILL.md) | Approved trust model, established local cryptographic facilities, canonicalization rules, and key lifecycle policy. | Domain-bound digests and signatures with protected keys, rotation, and precise verification outcomes. |
| [S11 Memory And Retrieval Engineering](S11-MEMORY-AND-RETRIEVAL-ENGINEERING/SKILL.md) | Memory and source contracts, access scope, provenance rules, and retrieval or deletion fixtures. | Attributed canonical memory, rebuildable indexes, conflict-aware retrieval, and validated context inputs. |
| [S12 Agent Workflow Engineering](S12-AGENT-WORKFLOW-ENGINEERING/SKILL.md) | Task graph, agent roles, skill manifests, resource limits, authority scope, and handoff contracts. | Bounded multi-agent execution with fenced ownership, durable handoffs, and separate review. |
| [S13 Model Inference Qualification](S13-MODEL-INFERENCE-QUALIFICATION/SKILL.md) | Exact model artifact, runtime configuration, target hardware, task fixtures, and locality policy. | A measured capability and resource envelope with inference, streaming, cancellation, and cleanup evidence. |
| [S14 Tool Execution Boundary Engineering](S14-TOOL-EXECUTION-BOUNDARY-ENGINEERING/SKILL.md) | Tool manifest, exact operation proposal, resource identities, isolation capabilities, and effect observation plan. | A governed adapter with exact-input binding, qualified restrictions, stop behavior, and receipts. |
| [S15 Desktop Interface Implementation](S15-DESKTOP-INTERFACE-IMPLEMENTATION/SKILL.md) | Approved user workflows, native command contracts, accessibility requirements, and authoritative state events. | A usable native interface with exact decision surfaces, recoverable drafts, and observed outcome presentation. |
| [S16 Test Generation And Execution](S16-TEST-GENERATION-AND-EXECUTION/SKILL.md) | Requirements, unit specifications, canonical contracts, inspected test tooling, and controlled fixtures. | Executed source-bound tests with independent oracles and explicit pass, fail, blocked, skipped, or not-executed states. |
| [S17 Failure Injection And Recovery](S17-FAILURE-INJECTION-AND-RECOVERY/SKILL.md) | State and effect boundaries, controlled test environment, recovery rules, and fault-injection points. | Reproducible interruption evidence and validated safe resume, compensation, or uncertainty handling. |
| [S18 Adversarial Security Review](S18-ADVERSARIAL-SECURITY-REVIEW/SKILL.md) | Explicitly authorized isolated targets, threat boundaries, source changes, and security acceptance cases. | Reproducible boundary findings with impact, exact evidence, and verified repairs. |
| [S19 Evidence Chain Validation](S19-EVIDENCE-CHAIN-VALIDATION/SKILL.md) | Operation records, artifacts, signatures, lineage, required evidence profile, and trust context. | A verification result separating integrity, attribution, completeness, observed behavior, and unresolved gaps. |
| [S20 Performance And Resource Analysis](S20-PERFORMANCE-AND-RESOURCE-ANALYSIS/SKILL.md) | Target hardware, representative workloads, explicit thresholds, resource telemetry, and baseline measurements. | Reproducible performance findings and qualified resource admission limits. |
| [S21 Cross Subsystem Integration](S21-CROSS-SUBSYSTEM-INTEGRATION/SKILL.md) | Approved contract revisions, mapped local units, dependency graph, source baseline, and migration plan. | Incrementally integrated native paths with compatibility, recovery, and owner-workflow evidence. |
| [S22 Documentation And Traceability](S22-DOCUMENTATION-AND-TRACEABILITY/SKILL.md) | Accepted implementation behavior, requirements, test results, source and artifact identities, and existing documentation. | Current file, contract, operation, migration, and release guidance with validated links. |
| [S23 Release Qualification](S23-RELEASE-QUALIFICATION/SKILL.md) | Exact candidate artifacts, source and dependency manifests, mandatory gates, target environments, and update or rollback rules. | An installed-runtime qualification record and accurate release decision for the exact candidate. |
| [S24 Independent Reproduction](S24-INDEPENDENT-REPRODUCTION/SKILL.md) | Producer deliverables, exact source and environment references, acceptance criteria, and raw evidence. | A separately produced verification report with reproduced results and explicit discrepancies. |
| [S25 No Proof No Claim Verification](S25-NO-PROOF-NO-CLAIM-VERIFICATION/SKILL.md) | A proposed completion statement, artifact references, execution records, tests, and known evidence gaps. | A claim ledger classifying each statement as supported, contradicted, incomplete, or not-executed. |
