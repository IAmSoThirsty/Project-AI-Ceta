# S21 purpose

Use this construction skill to produce: **Incrementally integrated native paths with compatibility, recovery, and owner-workflow evidence.**

The required input is: Approved contract revisions, mapped local units, dependency graph, source baseline, and migration plan.

The skill's distinguishing procedure is: Integrate foundations first; adapt existing owners rather than duplicate them; validate producer-consumer pairs; migrate data safely; test real action paths; preserve rollback and exact source mapping.

Success is measured by this oracle: **The full workflow uses one canonical authority, state, and evidence path without bypasses.** The specifically adverse condition is: **A second hidden implementation creates conflicting sources of truth.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
