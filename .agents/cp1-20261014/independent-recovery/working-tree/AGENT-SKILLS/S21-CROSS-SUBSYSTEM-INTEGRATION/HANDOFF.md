# S21 handoff

## Transfer result

Incrementally integrated native paths with compatibility, recovery, and owner-workflow evidence.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: The full workflow uses one canonical authority, state, and evidence path without bypasses.

The receiver also inspects evidence for the adverse fixture: A second hidden implementation creates conflicting sources of truth. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
