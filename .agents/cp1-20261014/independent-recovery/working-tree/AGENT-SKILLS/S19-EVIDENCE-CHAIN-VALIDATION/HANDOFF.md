# S19 handoff

## Transfer result

A verification result separating integrity, attribution, completeness, observed behavior, and unresolved gaps.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Every accepted claim is tied to current admissible evidence and every gap remains visible.

The receiver also inspects evidence for the adverse fixture: A valid signature is mistaken for proof of successful behavior or factual truth. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
