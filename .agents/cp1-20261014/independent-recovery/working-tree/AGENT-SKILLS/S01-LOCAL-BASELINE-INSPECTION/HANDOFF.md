# S01 handoff

## Transfer result

A source-hashed inventory, entry-point map, current test catalog, and observed integration decisions.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Every proposed real source path exists in the inspected baseline or has an explicit approved create decision.

The receiver also inspects evidence for the adverse fixture: A remote or remembered layout conflicts with the actual local files. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
