# S01 purpose

Use this construction skill to produce: **A source-hashed inventory, entry-point map, current test catalog, and observed integration decisions.**

The required input is: An owner-selected local CETA root, permitted read scope, and the logical-unit registry.

The skill's distinguishing procedure is: Resolve the selected root and link boundaries; inspect language and build metadata; enumerate canonical data and authority owners; inspect tests and release paths; classify reuse, extend, and create decisions from evidence.

Success is measured by this oracle: **Every proposed real source path exists in the inspected baseline or has an explicit approved create decision.** The specifically adverse condition is: **A remote or remembered layout conflicts with the actual local files.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
