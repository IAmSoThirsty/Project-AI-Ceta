# S22 handoff

## Transfer result

Current file, contract, operation, migration, and release guidance with validated links.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: A reader can navigate requirement to implementation to test to evidence without invented references.

The receiver also inspects evidence for the adverse fixture: A completion report claims work solely because it appears in a plan. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
