# S22 purpose

Use this construction skill to produce: **Current file, contract, operation, migration, and release guidance with validated links.**

The required input is: Accepted implementation behavior, requirements, test results, source and artifact identities, and existing documentation.

The skill's distinguishing procedure is: Trace requirements to files and tests; describe actual behavior; identify exact evidence; preserve local integration decisions; validate references and examples; label proposed and observed work separately.

Success is measured by this oracle: **A reader can navigate requirement to implementation to test to evidence without invented references.** The specifically adverse condition is: **A completion report claims work solely because it appears in a plan.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
