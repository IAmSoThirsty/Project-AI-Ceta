# S15 handoff

## Transfer result

A usable native interface with exact decision surfaces, recoverable drafts, and observed outcome presentation.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Critical approval, denial, stop, and recovery workflows function through accessible controls.

The receiver also inspects evidence for the adverse fixture: A control looks safe while an alternate keyboard or IPC path still performs an unauthorized effect. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
