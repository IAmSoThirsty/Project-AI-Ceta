# S20 handoff

## Transfer result

Reproducible performance findings and qualified resource admission limits.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: The system stays within its declared envelope and stop remains responsive under load.

The receiver also inspects evidence for the adverse fixture: Averages hide severe stalls or estimates are labeled as observed measurements. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
