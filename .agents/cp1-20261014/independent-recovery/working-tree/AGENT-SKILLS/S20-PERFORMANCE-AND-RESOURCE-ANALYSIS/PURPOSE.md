# S20 purpose

Use this construction skill to produce: **Reproducible performance findings and qualified resource admission limits.**

The required input is: Target hardware, representative workloads, explicit thresholds, resource telemetry, and baseline measurements.

The skill's distinguishing procedure is: Measure warm and cold paths; record peaks and tail latency; model context and concurrency growth; reserve control capacity; test pressure and cleanup; compare before and after with the same workload.

Success is measured by this oracle: **The system stays within its declared envelope and stop remains responsive under load.** The specifically adverse condition is: **Averages hide severe stalls or estimates are labeled as observed measurements.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
