# S02 handoff

## Transfer result

A requirement-to-unit map with measurable outputs, dependency edges, and acceptance oracles.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: No approved requirement is orphaned, silently narrowed, or replaced by a vague completion label.

The receiver also inspects evidence for the adverse fixture: A difficult requirement is dropped to make the plan appear complete. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
