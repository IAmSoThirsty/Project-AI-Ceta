# S02 purpose

Use this construction skill to produce: **A requirement-to-unit map with measurable outputs, dependency edges, and acceptance oracles.**

The required input is: Approved product goals, exact user requirements, constraints, and existing acceptance obligations.

The skill's distinguishing procedure is: Preserve exact requirements; split compound goals into testable behaviors; identify authority and data consequences; assign one owner; define completion evidence; retain ambiguities as explicit decisions.

Success is measured by this oracle: **No approved requirement is orphaned, silently narrowed, or replaced by a vague completion label.** The specifically adverse condition is: **A difficult requirement is dropped to make the plan appear complete.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
