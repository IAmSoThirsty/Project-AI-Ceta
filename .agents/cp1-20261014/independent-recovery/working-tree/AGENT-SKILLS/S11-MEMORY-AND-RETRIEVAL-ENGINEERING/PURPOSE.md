# S11 purpose

Use this construction skill to produce: **Attributed canonical memory, rebuildable indexes, conflict-aware retrieval, and validated context inputs.**

The required input is: Memory and source contracts, access scope, provenance rules, and retrieval or deletion fixtures.

The skill's distinguishing procedure is: Preserve originals; label inference and explicit statements; index committed versions; filter access before exposure; retain contradictions; propagate corrections and deletions through caches and summaries.

Success is measured by this oracle: **Retrieved records retain correct sources and revoked or deleted content cannot reappear through derived indexes.** The specifically adverse condition is: **A summary erases an explicit correction or turns speculation into a user statement.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
