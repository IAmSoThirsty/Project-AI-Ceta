# S11 handoff

## Transfer result

Attributed canonical memory, rebuildable indexes, conflict-aware retrieval, and validated context inputs.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Retrieved records retain correct sources and revoked or deleted content cannot reappear through derived indexes.

The receiver also inspects evidence for the adverse fixture: A summary erases an explicit correction or turns speculation into a user statement. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
