# S18 purpose

Use this construction skill to produce: **Reproducible boundary findings with impact, exact evidence, and verified repairs.**

The required input is: Explicitly authorized isolated targets, threat boundaries, source changes, and security acceptance cases.

The skill's distinguishing procedure is: Trace untrusted inputs to privileged effects; test injection, traversal, replay, stale identity, secret leakage, and extension escape; inspect native enforcement; reproduce fixes independently; preserve evidence.

Success is measured by this oracle: **Each claimed boundary holds under the specified adversarial fixtures or has an explicit blocking finding.** The specifically adverse condition is: **A review tests production targets without scope approval or substitutes model confidence for observed enforcement.** Preserve this distinction in planning, implementation, testing, and reporting. The skill does not expand the assigned task's scope, change constitutional rules, or grant execution authority.
