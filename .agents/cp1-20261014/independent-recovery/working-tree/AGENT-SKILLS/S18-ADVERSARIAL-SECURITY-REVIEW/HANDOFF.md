# S18 handoff

## Transfer result

Reproducible boundary findings with impact, exact evidence, and verified repairs.

## Required handoff

Identify the task, logical units, mapped local paths, source and artifact digests, contract revisions, performed procedure, actual verification records, and remaining obligations. Include uncertainty, failed checks, pending decisions, cancellation state, and any active ownership or resource leases. The receiver validates exact references before accepting the handoff.

## Acceptance

The receiver checks: Each claimed boundary holds under the specified adversarial fixtures or has an explicit blocking finding.

The receiver also inspects evidence for the adverse fixture: A review tests production targets without scope approval or substitutes model confidence for observed enforcement. A summary alone is insufficient. If any referenced artifact or source revision changed, issue a new handoff revision and invalidate stale review assumptions. Use [the shared construction handoff contract](../../AGENT-ROLES/CROSS-AGENT-HANDOFF-CONTRACT.md).
