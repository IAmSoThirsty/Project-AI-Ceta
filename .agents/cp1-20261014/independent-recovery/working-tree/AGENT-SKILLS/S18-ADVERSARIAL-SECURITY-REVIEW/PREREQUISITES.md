# S18 prerequisites

## Domain prerequisites

Explicitly authorized isolated targets, threat boundaries, source changes, and security acceptance cases.

## Required readiness

The task has an owner-approved goal, exact local inspection scope, mapped unit IDs, applicable contract revisions, observable acceptance criteria, and a named review owner. The local baseline and relevant source digests are available. Effectful work has current scoped permission and a recovery plan appropriate to its consequences. Test fixtures are isolated from owner production data.

## Admission decision

Verify these prerequisites rather than assuming them from conversation summaries or directory names. If a required source, environment, permission, or contract is unavailable, preserve existing evidence and identify the blocked step. Do not invent local implementation details, substitute a remote layout, or silently widen the task. The relevant domain failure to anticipate is: A review tests production targets without scope approval or substitutes model confidence for observed enforcement.
