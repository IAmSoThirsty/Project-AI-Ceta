# Canonical interface contracts

This directory contains 43 individually specified contracts in seven categories. Every contract identifies a schema owner, consumers, typed fields, validation, lifecycle, errors, compatibility, and conformance cases. The common rules define operation envelopes, types, time, content binding, authority, uncertainty, privacy, and bootstrap distinctions.
