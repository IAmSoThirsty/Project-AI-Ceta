## Component and subsystem tests

| Component | Integrated behavior | Invariant |
| --- | --- | --- |
| [09.01](09.01-MODEL-REGISTRY/README.md) | Register model artifacts and declared capabilities; validate format and content; qualify on the target environment; publish availability separately from configuration. | Declared model capability requires observed qualification before it is used for admission. |
| [09.02](09.02-INFERENCE-RUNTIME/README.md) | Admit an inference request; pin model and context; stream ordered output; observe cancellation and usage; seal the response with provenance and outcome status. | Partial generated output never masquerades as a complete validated action proposal. |
| [09.03](09.03-MODEL-ROUTING/README.md) | Match task requirements; evaluate qualified candidates and resource limits; select a model; request approval for changed data boundaries; record routing and fallback decisions. | Fallback preserves authority, privacy, task semantics, and evidence obligations. |
| [09.04](09.04-MODEL-ADMISSION/README.md) | Inspect actual hardware; estimate model and context working sets; reserve headroom; run qualification probes; admit only within tested limits. | Installed artifact size is not a substitute for peak runtime memory measurement. |
| [09.05](09.05-MODEL-INTERFACES/README.md) | Normalize inference contracts; validate transport and data scope; dispatch through the chosen adapter; normalize usage and errors; preserve native evidence. | Adapters translate contracts and cannot widen authority or change data locality silently. |
| [09.06](09.06-MODEL-EVALUATION/README.md) | Run versioned representative fixtures; score task outcomes and boundary behavior; compare against declared qualification thresholds; retain full reproducibility metadata. | Model benchmarks are scoped measurements, not universal guarantees of truth or safety. |
| [09.07](09.07-MODEL-LIFECYCLE/README.md) | Acquire authorized artifact bytes; validate in staging; install atomically; configure; load under resource admission; unload and verify cleanup. | Model acquisition never executes downloaded content as an installation side effect. |
| [09.08](09.08-MODEL-CUSTOMIZATION/README.md) | Approve a customization objective and data scope; validate datasets; admit a bounded training job; checkpoint; evaluate a candidate artifact; activate only after qualification. | Learned model changes do not amend constitutional policy, user authority, or release qualification requirements. |
