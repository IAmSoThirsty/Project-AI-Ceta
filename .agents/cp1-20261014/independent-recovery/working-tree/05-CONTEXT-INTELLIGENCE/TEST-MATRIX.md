## Component and subsystem tests

| Component | Integrated behavior | Invariant |
| --- | --- | --- |
| [05.01](05.01-CONTEXT-INPUTS/README.md) | Resolve the active task and project; select authorized sources; preserve trust classification; exclude unrelated contexts; retain exact-source references. | Cross-project retrieval requires an explicit permitted scope, not semantic similarity alone. |
