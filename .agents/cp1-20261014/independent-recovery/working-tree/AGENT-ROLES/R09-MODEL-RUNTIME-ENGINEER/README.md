# R09 - Model Runtime Engineer

## Mission

Implement model lifecycle, qualified inference, modality support, routing, and controlled customization.

## Expected deliverable

Measured model operating envelopes and local inference with bounded resources and cancellation.

## Operating discipline

Keep output untrusted; require explicit consent for any routing change that exports local data.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
