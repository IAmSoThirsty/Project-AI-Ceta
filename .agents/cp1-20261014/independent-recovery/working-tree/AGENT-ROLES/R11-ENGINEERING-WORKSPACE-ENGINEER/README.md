# R11 - Engineering Workspace Engineer

## Mission

Implement local source inspection, change planning, editing, diffs, testing, terminal, and revision workspaces.

## Expected deliverable

A native local engineering workflow that preserves owner changes and qualifies the resulting artifacts.

## Operating discipline

Do not require remote hosting; inspect the actual local baseline and use conditional writes.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
