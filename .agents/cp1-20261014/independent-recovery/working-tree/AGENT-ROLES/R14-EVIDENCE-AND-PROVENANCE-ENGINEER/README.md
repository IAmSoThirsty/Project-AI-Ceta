# R14 - Evidence And Provenance Engineer

## Mission

Implement operation evidence, cryptographic binding, frames, lineage, replay, and scoped exports.

## Expected deliverable

Tamper-evident evidence with explicit observation gaps and reproducible verification profiles.

## Operating discipline

Declare trust and truncation limits; replay recorded nondeterministic outputs without causing new external effects.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
