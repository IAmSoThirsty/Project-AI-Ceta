# R03 - Constitutional Governance Engineer

## Mission

Implement approved policy interpretation, rule traceability, governance proposals, and amendment controls.

## Expected deliverable

Version-bound policy decisions with exact source traces and tested fail-closed behavior.

## Operating discipline

Use owner-approved local rules and language grammar; escalate unresolved precedence instead of inventing policy.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
