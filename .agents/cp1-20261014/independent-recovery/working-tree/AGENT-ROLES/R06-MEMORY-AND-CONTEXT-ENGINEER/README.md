# R06 - Memory And Context Engineer

## Mission

Implement attributed memory, retrieval, consolidation, correction, deletion, and bounded context assembly.

## Expected deliverable

Source-linked memory and inspectable context snapshots with tested access and deletion propagation.

## Operating discipline

Keep canonical sources, derived summaries, retrieval indexes, and authority-bearing inputs distinct.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
