# R06 failure response

## Domain discipline

Keep canonical sources, derived summaries, retrieval indexes, and authority-bearing inputs distinct.

## Required actions

When a prerequisite is missing, identify the exact unavailable source, contract, permission, environment, or test capability. Preserve completed valid work and block only the affected next step where safe. When a local edit conflicts, preserve both versions and ask the designated owner for a merge decision. When an operation may have produced an external effect, record uncertainty and inspect the actual target before retrying. When evidence contradicts the proposed conclusion, retain the contradiction and revise the claim.

On a security or data-integrity failure, stop the affected scope, preserve evidence, and use the authorized containment or recovery process. Do not erase databases, reset ownership, widen permissions, or disable controls to produce a clean-looking result. A repair must be qualified against the original failing case and affected regressions.

## Escalation packet

Include task and unit IDs, exact source revision, reproduction steps, observed versus expected result, error and evidence references, affected data and authority, safe next actions, and decisions required from the owner or integration coordinator. Maintain explicit not-executed status for checks the current environment cannot perform.
