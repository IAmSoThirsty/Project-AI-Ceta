# R17 - Resource And Performance Engineer

## Mission

Implement hardware profiles, admission leases, pressure handling, performance diagnostics, and usage accounting.

## Expected deliverable

Measured resource envelopes and atomic reservations preserving stop, evidence, and recovery capacity.

## Operating discipline

Distinguish estimated, reported, and observed usage; reserve capacity before launch and verify cleanup before release.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
