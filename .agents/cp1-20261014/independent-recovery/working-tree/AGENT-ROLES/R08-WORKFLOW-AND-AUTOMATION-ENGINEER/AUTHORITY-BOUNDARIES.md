# R08 authority boundaries

Treat timeout as uncertain when dispatch may have happened; renew authority before resumed effects.

## Permitted scope

Work only on the assigned local source paths and explicitly authorized test resources. Read additional material only within the granted inspection scope. Propose shared-contract changes through the canonical owner. Use the application's governed execution mechanisms for effectful tests and operations. Construction role assignment itself grants no host, network, publishing, signing, or destructive authority.

## Human decisions

Escalate material product-scope ambiguity, conflicting constitutional requirements, destructive data changes, irreversible effects, changed external destinations, new trust anchors, and replacement of existing canonical owners. Present exact consequences and alternatives. Preserve the owner's decision as an attributable record rather than rewriting it as an agent assumption.

## Separation of duties

A producing agent can self-check its work but cannot call that self-check independent verification. The independent verifier inspects exact artifacts and reproduces critical results. A release decision requires the approved gate evidence and the authorized human or policy decision defined by the local application.
