# Construction agent roles

These 21 roles organize future engineering work on the approved native architecture. They are distinct from deployed runtime agents. Each role has a mission, responsibility and authority boundaries, required skills, input and output contracts, handoff rules, failure behavior, and completion standard.

| Role | Mission | Expected deliverable |
| --- | --- | --- |
| [R01 Architecture Coordinator](R01-ARCHITECTURE-COORDINATOR/README.md) | Own architecture coherence, canonical interfaces, dependency decisions, and product-scope traceability. | An approved dependency and ownership map with every logical unit assigned once. |
| [R02 Existing System Reconciler](R02-EXISTING-SYSTEM-RECONCILER/README.md) | Inspect the owner-selected local CETA application and map this package to observed source and behavior. | A source-hashed inventory and reuse, extend, or create decision for every logical unit. |
| [R03 Constitutional Governance Engineer](R03-CONSTITUTIONAL-GOVERNANCE-ENGINEER/README.md) | Implement approved policy interpretation, rule traceability, governance proposals, and amendment controls. | Version-bound policy decisions with exact source traces and tested fail-closed behavior. |
| [R04 Identity And Authority Engineer](R04-IDENTITY-AND-AUTHORITY-ENGINEER/README.md) | Implement principal identity, authenticated sessions, scoped capability issuance, delegation, and revocation. | Authority flows with verified ancestry, exact proposal binding, and tested revocation races. |
| [R05 Companion Intelligence Engineer](R05-COMPANION-INTELLIGENCE-ENGINEER/README.md) | Implement dialogue, continuity, deliberation, explicit preferences, and governed task proposals. | A continuous companion workflow whose claims are grounded and whose actions use approved task contracts. |
| [R06 Memory And Context Engineer](R06-MEMORY-AND-CONTEXT-ENGINEER/README.md) | Implement attributed memory, retrieval, consolidation, correction, deletion, and bounded context assembly. | Source-linked memory and inspectable context snapshots with tested access and deletion propagation. |
| [R07 Agent Orchestration Engineer](R07-AGENT-ORCHESTRATION-ENGINEER/README.md) | Implement native skill lifecycle, bounded agent roles, task assignments, handoffs, and independent review. | Qualified skills and multi-agent execution with fenced ownership and evidence-backed outcomes. |
| [R08 Workflow And Automation Engineer](R08-WORKFLOW-AND-AUTOMATION-ENGINEER/README.md) | Implement durable task graphs, retries, checkpoints, schedules, event triggers, and recovery. | Restart-safe workflows with stable operation identities and explicit uncertain-effect reconciliation. |
| [R09 Model Runtime Engineer](R09-MODEL-RUNTIME-ENGINEER/README.md) | Implement model lifecycle, qualified inference, modality support, routing, and controlled customization. | Measured model operating envelopes and local inference with bounded resources and cancellation. |
| [R10 Tool And Execution Engineer](R10-TOOL-AND-EXECUTION-ENGINEER/README.md) | Implement tool schemas, governed dispatch, native effect boundaries, isolation, and stop behavior. | Exact-input and exact-target execution with independent effect observations and reliable stopping. |
| [R11 Engineering Workspace Engineer](R11-ENGINEERING-WORKSPACE-ENGINEER/README.md) | Implement local source inspection, change planning, editing, diffs, testing, terminal, and revision workspaces. | A native local engineering workflow that preserves owner changes and qualifies the resulting artifacts. |
| [R12 Communication And UX Engineer](R12-COMMUNICATION-AND-UX-ENGINEER/README.md) | Implement native interface, conversation, voice, media, decisions, notifications, and maintenance views. | Accessible owner workflows backed by authenticated native commands and real runtime state. |
| [R13 Knowledge And Research Engineer](R13-KNOWLEDGE-AND-RESEARCH-ENGINEER/README.md) | Implement source ingestion, structured extraction, indexes, knowledge relationships, and cited synthesis. | Inspectable source-to-claim lineage preserving uncertainty, contradiction, and source independence. |
| [R14 Evidence And Provenance Engineer](R14-EVIDENCE-AND-PROVENANCE-ENGINEER/README.md) | Implement operation evidence, cryptographic binding, frames, lineage, replay, and scoped exports. | Tamper-evident evidence with explicit observation gaps and reproducible verification profiles. |
| [R15 Security And Cryptography Engineer](R15-SECURITY-AND-CRYPTOGRAPHY-ENGINEER/README.md) | Implement protected keys, secrets, trust boundaries, incident containment, and security assurance. | Qualified controls and trust chains with least-authority secret access and safe recovery. |
| [R16 State And Recovery Engineer](R16-STATE-AND-RECOVERY-ENGINEER/README.md) | Implement canonical state, transactions, snapshots, migration, archival, and interrupted-operation recovery. | Durable consistent state with tested recovery that preserves drafts, identity, and security history. |
| [R17 Resource And Performance Engineer](R17-RESOURCE-AND-PERFORMANCE-ENGINEER/README.md) | Implement hardware profiles, admission leases, pressure handling, performance diagnostics, and usage accounting. | Measured resource envelopes and atomic reservations preserving stop, evidence, and recovery capacity. |
| [R18 Integration Engineer](R18-INTEGRATION-ENGINEER/README.md) | Integrate native extensions and all subsystem contracts into the inspected local application. | Compatible producer-consumer paths, isolated optional extensions, and verified incremental integration. |
| [R19 Test And Qualification Engineer](R19-TEST-AND-QUALIFICATION-ENGINEER/README.md) | Design and execute contract, integration, recovery, security, performance, and user-workflow qualification. | Current source-bound test results and explicit gate decisions for every required acceptance obligation. |
| [R20 Independent Adversarial Verifier](R20-INDEPENDENT-ADVERSARIAL-VERIFIER/README.md) | Independently reproduce critical results, inspect actual artifacts, and test authority and recovery boundaries. | A separate verification report identifying reproduced outcomes, contradictions, and unmet obligations. |
| [R21 Build And Release Engineer](R21-BUILD-AND-RELEASE-ENGINEER/README.md) | Build, package, install-test, version, update, roll back, and qualify the complete native product. | A manifest-bound release candidate with installed-runtime evidence and tested data-preserving maintenance. |
