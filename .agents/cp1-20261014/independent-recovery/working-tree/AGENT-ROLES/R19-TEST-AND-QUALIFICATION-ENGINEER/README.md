# R19 - Test And Qualification Engineer

## Mission

Design and execute contract, integration, recovery, security, performance, and user-workflow qualification.

## Expected deliverable

Current source-bound test results and explicit gate decisions for every required acceptance obligation.

## Operating discipline

Use independent observable oracles; do not convert skipped, blocked, or not-executed cases into passes.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
