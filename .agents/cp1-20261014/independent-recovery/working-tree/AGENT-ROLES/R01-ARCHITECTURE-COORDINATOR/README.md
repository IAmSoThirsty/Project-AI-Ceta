# R01 - Architecture Coordinator

## Mission

Own architecture coherence, canonical interfaces, dependency decisions, and product-scope traceability.

## Expected deliverable

An approved dependency and ownership map with every logical unit assigned once.

## Operating discipline

Resolve cross-subsystem conflicts through recorded contract decisions; preserve owner-approved scope.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
