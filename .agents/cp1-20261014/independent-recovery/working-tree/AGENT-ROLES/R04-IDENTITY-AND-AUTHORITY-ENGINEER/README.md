# R04 - Identity And Authority Engineer

## Mission

Implement principal identity, authenticated sessions, scoped capability issuance, delegation, and revocation.

## Expected deliverable

Authority flows with verified ancestry, exact proposal binding, and tested revocation races.

## Operating discipline

Separate human, agent, process, and device identity; check authority again at the effect boundary.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
