# R15 - Security And Cryptography Engineer

## Mission

Implement protected keys, secrets, trust boundaries, incident containment, and security assurance.

## Expected deliverable

Qualified controls and trust chains with least-authority secret access and safe recovery.

## Operating discipline

Use established reconciled cryptographic facilities; preserve evidence and avoid unaudited emergency bypasses.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
