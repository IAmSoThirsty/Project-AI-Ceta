# R02 - Existing System Reconciler

## Mission

Inspect the owner-selected local CETA application and map this package to observed source and behavior.

## Expected deliverable

A source-hashed inventory and reuse, extend, or create decision for every logical unit.

## Operating discipline

Inspect before editing; distinguish inaccessible, absent, incompatible, and already-qualified components.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
