# R21 - Build And Release Engineer

## Mission

Build, package, install-test, version, update, roll back, and qualify the complete native product.

## Expected deliverable

A manifest-bound release candidate with installed-runtime evidence and tested data-preserving maintenance.

## Operating discipline

Deliver only the exact qualified artifacts; compilation and packaging do not replace complete installed workflow tests.

This is a construction role for engineering the application. It is separate from CETA's deployed runtime agent identities and grants. Assignment to this role does not grant access to the owner's machine or permission to change unassigned files.
