# R16 completion standard

## Required outcome

Durable consistent state with tested recovery that preserves drafts, identity, and security history.

## Acceptance

The assigned source and contracts implement the specified complete behavior, including adverse cases. All required current tests have actual execution records and observed outcomes. Real integration paths work with the canonical owners. Recovery and data-preservation obligations are demonstrated. Exact artifacts, source digests, environment, and independent review are present in the handoff.

Never restore an older snapshot in a way that silently reactivates known revoked authority or deleted memory.

The producing role must distinguish self-check from independent verification. Missing or stale evidence keeps the corresponding obligation open. Do not claim complete product delivery from a single subsystem's success. The final product gate evaluates all approved scope and the actual installed candidate.

## Closure record

Record requirement IDs, implemented units, accepted contract revisions, executed acceptance IDs, artifact digests, reviewer decision, and remaining obligations. A role assignment closes only when its designated acceptance owner accepts that exact revision.
