# Construction agent handoff graph

Owner-approved scope passes to R01 architecture coordination and R02 local reconciliation. Canonical contract decisions pass to their specialist owners. Each subsystem's primary builder receives mapped files, acceptance criteria, and bounded write ownership. R18 coordinates shared integration; R19 coordinates test execution; R20 independently reproduces critical results. R21 assembles and install-tests the exact release candidate only after mandatory gates are satisfied.

The normal sequence is baseline inspection, contract approval, implementation assignment, source and test construction, real integration, independent verification, and release qualification. Failed checks return to the responsible owner with exact reproduction evidence. Scope or authority conflicts return to the designated human decision, not to agent majority voting. Shared-file conflicts suspend publication until ownership is resolved.

A handoff carries task and unit IDs, exact source and artifact digests, contract revisions, actual results, remaining obligations, uncertain effects, cancellation state, and leases. The receiver acknowledges the exact handoff revision and validates references before taking ownership. Role reuse does not merge runtime identities, and the producer does not independently approve its own work.
