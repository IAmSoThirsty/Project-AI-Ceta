# CETA Native Architecture Construction Pack

Start with [MASTER-README.md](MASTER-README.md).

This documentation-only construction package contains the complete approved subsystem tree, individual build instructions for every planned implementation file, canonical contracts, construction agent roles and skills, dependency maps, integration procedures, and acceptance requirements.

The local working application was not inspected while preparing this archive. The first engineering step is to map logical units to the actual local source and preserve existing compliant components and user data. No runtime implementation code is included.

For visual navigation use [the full directory tree](DIRECTORY-TREE.md). For package verification use [the completeness report](MANIFESTS-AND-TRACEABILITY/PACKAGE-COMPLETENESS-REPORT.md) and [the integrity manifest](PACKAGE-INTEGRITY.md).
